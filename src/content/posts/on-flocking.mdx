# On Flocking Simulations

Craig Reynolds' **boids** algorithm demonstrates how simple local rules produce complex emergent behavior. Each agent follows three principles:

1. **Separation** — avoid crowding nearby agents
2. **Alignment** — steer towards the average heading of neighbors
3. **Cohesion** — move toward the average position of neighbors

## Moving to the GPU

Running thousands of boids on the CPU quickly becomes a bottleneck. WebGPU compute shaders let us move the neighbor search and force calculations to massively parallel hardware.

The key insight is that each boid's update is independent — making it embarrassingly parallel and a perfect fit for GPU workgroups.

```wgsl
@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) id: vec3u) {
  let i = id.x;
  // each thread updates one boid
}
```
